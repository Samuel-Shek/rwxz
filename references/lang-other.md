# 其他语言写作适配

输出语言不是中文或英文时读本文件。SKILL.md 的通用原则照常适用；这里给的是“按目标语言重新校准”的方法，不是把中文或英文规则翻译过去。

## 1. 先定四件事

1. 语言与地区：西班牙语是墨西哥还是西班牙，葡萄牙语是巴西还是葡萄牙，法语是法国还是加拿大，阿拉伯语是标准语还是方言。用户或读者地区决定用词、拼写、货币和日期格式。
2. 礼貌层级：这门语言怎样表达“正式 / 客气 / 亲近”，用哪个人称和动词形式。
3. 文体惯例：这门语言里这种文体的固定格式（邮件开头结尾、商品描述常见结构、公告格式）。惯例要遵守，不当成套话删掉。
4. 篇幅单位：词数、字符数还是行数。中日韩按字符，拼音文字通常按词；按用户说的单位实际计数。

## 2. 常见语言的要点

以下只列最容易出错的地方，不是完整规范。

| 语言 | 礼貌与称谓 | 标点、书写与格式 | 常见误区 |
|---|---|---|---|
| 日语 | 商务文字用丁寧語打底，对对方动作用尊敬語，对己方动作用謙譲語；对外邮件称对方公司「貴社」、己方「弊社」 | 全角标点「」、。；商务邮件常见结构：宛名 → 挨拶 → 名乗り → 本文 → 結び → 署名；日期「3月5日（木）」；正文日期同样要放进完整句子，不要堆成笔记式罗列 | 敬语叠用过度（二重敬語）；把中文汉字词直接当日语用；句子过长、主语不清 |
| 韩语 | 对外正式用 합니다체，服务与客户沟通常用 해요체；称谓加 님 | 空格（띄어쓰기）规则影响可读性；日期「3월 5일」 | 汉字词过多显得生硬；敬语层级前后不一致 |
| 德语 | 商务默认 Sie，用户明确要求或品牌语气亲近时才用 du；称谓 Sehr geehrte Frau / Sehr geehrter Herr + 姓 | 名词首字母大写；正文里日期时间要写成完整句法「am Donnerstag, dem 5. März, um 9 Uhr」，不要写成笔记式「Donnerstag, 5. März, 9 Uhr」；小数用逗号 | Sie 与 du 混用；从英语直译的长名词串；英文式标题大写 |
| 法语 | 商务默认 vous；称谓 Madame / Monsieur | 法国法语在 ; : ! ? 前加不换行空格，引号用 « »；加拿大法语规则略有不同 | 英语借词过多；句子里 vous 与 tu 混用 |
| 西班牙语 | 拉美多用 usted 表示礼貌，品牌对消费者常用 tú；西班牙对多人用 vosotros，拉美用 ustedes | 问句和感叹句开头加 ¿ ¡；墨西哥用 computadora、celular，西班牙用 ordenador、móvil；货币按当地格式（$1,250 MXN） | 地区词汇混用；逐字直译英语营销句 |
| 葡萄牙语 | 巴西多用 você，葡萄牙正式场合常用 o senhor / a senhora | 巴西与葡萄牙拼写和词汇不同（ônibus / autocarro） | 巴葡与欧葡混用 |
| 阿拉伯语、希伯来语 | 按关系选择正式程度 | 从右到左书写；混排数字、英文、URL 时注意方向；阿拉伯语标点有专用形式（، ؛ ؟） | 在从左到右的文档里直接粘贴导致顺序错乱 |

## 3. 通用校准问题

写完用目标语言问自己：

1. 这门语言的母语者在这个场合会这样开头、这样收尾吗？
2. 称谓、人称和敬语全文一致吗？
3. 有没有从中文或英文直译过来的句子结构和习语？
4. 数字、日期、时间、货币、标点符合当地格式吗？
5. 篇幅按指定单位实际数过吗？

## 4. 能力边界

- 本 Skill 只在少数中英文以外的样例上做过对照测试（见版本记录），不代表这些语言的质量已经全面验证。
- 对外正式发布的非中英文内容（法律、医疗、合同、广告投放），建议交给该语言的母语者复核，并在交付时提醒用户。
- 对某种语言的礼貌规范或地区用法没有把握时，选更中性、更正式的写法，并在成品后用一行说明不确定的地方。
