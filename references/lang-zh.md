# 中文写作适配

输出含中文时读本文件。这里只放中文特有的问题；目的、读者、事实等通用要求见 SKILL.md。

## 1. 句法：别按英文的骨架写中文

| 问题 | 例子 | 改法 |
|---|---|---|
| 虚化动词 + 名词化 | 对库存数据进行了核对；做出暂停招聘的决定；加以改进 | 直接用动词：核对了库存数据；决定暂停招聘；改进 |
| 长定语前置 | 一款由深圳团队历时半年打造的、专为户外露营设计的便携咖啡机 | 拆开说：这款便携咖啡机专为露营设计，深圳团队做了半年 |
| “被”字滥用 | 这个功能被很多用户喜欢；会议被推迟到下周 | 用主动句或无标记被动：很多用户喜欢这个功能；会议推迟到下周 |
| 介词框架堆叠 | 对于……来说；关于……的问题；在……的过程中；通过……使…… | 删掉框架，直接说主语和动作。“通过 A 使 B”常缺主语，改成“A 让 B” |
| 目的状语套话 | 此举的目的是为了降低成本；出于安全的目的 | 此举是为了降低成本；为了安全 |
| 代词回指过多 | 它、他们、这一点、该产品反复出现 | 中文常省略主语或直接重复名词 |
| 连接词堆叠 | 因此、然而、此外、同时、并且、从而 句句都有 | 中文靠语序和意合衔接，逻辑清楚时删掉 |
| “的”连用 | 公司的新产品的市场的反馈 | 同一短语里“的”一般不超过两个：新产品的市场反馈 |
| 量词滥用 | 这是一个非常重要的问题；我们有了一个新的想法 | 不必要的“一个”删掉 |
| 抽象名词做主语 | 效率的提高得到了实现 | 让人或事物做主语：效率提高了 |
| 抽象名词压缩句 | 以协作张力激活执行底色；给方案保留行动余量 | 把余量、意味、分寸、边界、节奏、底色、课题这类抽象词塞进短标题或短句，读者要先解码才懂。拆开写清谁、做什么：请两位同事分别核对数据和文案；排期先留出两天处理返工 |

## 2. 搭配与用词

- 动宾搭配要对：提高效率、解决问题、降低成本；不说“提升问题”“加强效率”。
- 口语和书面语不混搭：“搞定”“贼好用”不进正式说明；“兹”“拟于”不进朋友圈。
- 同一个概念全文用同一个词，不为避免重复换同义词，尤其是术语和产品名。
- 数字：统计、计量用阿拉伯数字；成语、惯用语和不表示确数的用汉字（“三五天”“一两万字”）。

## 3. 标点

- 中文正文用全角标点：，。？！：；（）。
- 引号：简体大陆用“”，里层用‘’；繁体港台常用「」，里层『』。跟随用户或读者地区，全文统一。不在中文里用半角 `""`。
- 省略号用“……”，破折号用“——”。破折号用来强调或插入说明，不当逗号用。
- 中西文、中文与数字之间是否加空格，按用户或平台习惯；没有习惯时交给 `chinese-typography` 统一。
- 写完可跑 `scripts/text_check.py punct <文件>` 查中文旁边的半角标点。

## 4. 简繁与地区用语

- 用户指定优先。繁体不等于简体逐字转码，词汇也要换。

| 简体（大陆） | 繁体（台湾） | 繁体（香港） |
|---|---|---|
| 软件 | 軟體 | 軟件 |
| 信息 | 資訊 | 資訊 |
| 视频 | 影片 / 視訊 | 影片 / 視頻 |
| 网络 | 網路 | 網絡 |
| 出租车 | 計程車 | 的士 |
| 自来水、饮用水 | 自來水 | 食水 |
| 咨询（电话） | 洽詢 | 查詢 |
| 通知（楼宇告示） | 公告 | 通告 |
| 质量 | 品質 | 質素 / 品質 |
| 地铁 | 捷運 | 港鐵 / 地鐵 |

- 香港对外正式文字以标准书面中文加香港惯用词为主；除非用户要求，不写粤语口语（“唔該”“嘅”）。
- 大陆通知常用“特此通知”“请……”；香港物业通知常见“敬請”“不便之處，敬請見諒”。这些惯用语每篇最多用一次，不叠用（同一段里“敬請……”“懇請……”“敬希……”接连出现就是堆砌）。给住户、客户带来不便的通告，保留一句致歉惯用语。
- 日期、时间写法跟随地区：大陆“3 月 8 日下午 2 点”；香港常见“3月8日（星期六）下午2時”。

## 5. 语域

- 正式说明、通知：短句、主动、先结论；不用口头禅，不用感叹号堆情绪。
- “正式但友好”不等于公文腔。用同事当面交代事情的语气写：说清不做会怎样、具体做哪一步（“下周三前没交，系统就锁定，到时只能找财务手工补录”），少用“为进一步加强”“请务必高度重视”“特此通知”这类套话，一篇里同一句提醒不说两遍。
- 卖点和培训话术：写成读者能直接说出口的话（“充一次电够跑两天，出差不用带充电器”），不写“是重要卖点”“是硬指标”“值得重点介绍”这类贴标签的句子。
- 公众号、朋友圈：可以口语化、第一人称、有停顿感。“其实”“说真的”这类口语转折只在自然处用，不定额，同一个词全文不反复出现。
- 商品页、闲鱼：信息完整优先，买家要的信息（是什么、交付什么、要提供什么、多久、价格、不做什么）一眼能找到。

## 6. 中文 AI 腔信号

出现不等于错，但每一处都要问：删掉或换成具体说法，读者会损失什么？

- 空转开头：在当今时代、随着……的发展、说到……相信大家都不陌生、众所周知。
- 空转过渡：值得注意的是、值得一提的是、不可否认、毫无疑问、换句话说、本质上、说白了（口语文体里偶尔用可以）。
- 空壳词：赋能、闭环、抓手、底层逻辑、生态、无缝、至关重要、深入探讨、相互交织。
- 流水线结构：首先 / 其次 / 最后；综上所述；总而言之。
- 工整排比和否定排比：“不仅仅是 A，更是 B”“是 A 的 B，是 C 的 D，是 E 的 F”。
- 抽象形容代替动作：“我感到非常震撼”不如写出当时做了什么。
- 一句一段连续四段以上。

## 7. 中文专项检查

写完对照：

1. 有没有“进行 / 做出 / 加以 + 名词”可以直接改成动词？
2. 有没有超过 20 字、读者要回头再读的长定语？
3. “被”“对于”“通过……使”“的”是否过多？
4. 连接词删掉后逻辑还清楚吗？清楚就删。
5. 有没有一句话塞了三个以上信息点、读者要换气的长句？拆开，用“不过”“这样”这类短连接承接。
6. 标点全角、引号样式统一、简繁和地区用语统一？
7. 字数按 Word 口径实际数过？
8. 每个小标题和判断句，原样念给一个不懂行的人听，他能一遍复述出意思吗？要先想一下才明白的，拆成具体的人和动作重写。
9. 主语和动作搭得上吗？每句找出“谁”和“干什么”，主语是东西、想法或抽象名词时，确认它真能做这个动作。“新流程能讲清楚、跑起来”不行，流程自己不会讲，改成“新流程跑得起来，负责人也讲得清楚”。
10. 同一句里有没有互相打架的意思？“守住原计划的同时随时调整计划”“稳定地改变”这类句子，读者会以为前后矛盾。原意通常是两件事分属不同对象（上线日期不变、具体分工可以调），拆开写清各自指什么。
11. 收尾句、金句单独再读一遍。动词要有具体对象：“把理由讲清”要说讲清什么，“把时间留出来”要说给谁、什么时候留。两个“把……”并排的口号句，读着顺口，读者却不知道该做哪件事；“你陪着他，……”这种开头又像在给读者派任务。改成读者照着就能做的一件事：“你陪着他，把理由讲清，把时间留出来”→“催他，不如跟他讲清为什么；他忙完了，给他留一段没人打扰的时间。”
12. 这些检查只能靠人逐句读，脚本扫不出来。
