# 调研与核查提示词模板

完整档需要写法调研或事实核查时使用。只在宿主真的能联网或派子代理时用；做不到就跳过调研，事实部分按 SKILL.md 第 5 节标 `[待核实]`。

提示词用任务所在语言写即可；下面给中文版，英文任务可按同样结构改写。

## A. 写法调研

```
我在帮用户写一篇关于 <主题> 的 <渠道/文体> 稿件，目标读者是 <读者>，语言是 <语言>。

请做下面三件事，控制在 1000 字以内回报：

【任务一】找这个题材、这种语言里公认写得好的几位作者或媒体，提炼他们的核心写法（每位 2–4 条具体动作，不要泛泛说“语言生动”）。

【任务二】搜一下有没有高质量的公开写作指南、风格手册或开源写作 Skill/Prompt 与这个题材相关。

【任务三】综合以上，给一份能直接用上的写作框架：
1. 开头的 3–5 种写法及适用场景
2. 中段做出洞察感的 3–5 种结构动作
3. 用读者熟悉的类比讲复杂概念的思路
4. 节奏控制
5. 收尾或转化的 3–5 种写法
6. 这种语言里常见的“机器腔”信号

输出格式：
# 写法调研报告
## 一、作者核心动作
## 二、可借鉴的指南与 Skill
## 三、可直接落地的写作框架

不要写开场白或客套结尾，直接给内容。
```

## B. 事实核查

```
我要在一篇文章里用到下面几个事实。请逐条核实，200 字以内回复，每条标注「✅ 准确」「❌ 不准确，应改为 X」或「⚠️ 有争议」，并给出处：

1. <具体事实 1，包括年份、人物、地点、数字>
2. <具体事实 2>
3. <具体事实 3>

优先查一手来源：官方文献、原始论文、权威百科（Wikipedia、Stanford Encyclopedia of Philosophy 等）、官方统计。重点是核对，不是写文章。用当前宿主可用的联网检索工具查证。
```
